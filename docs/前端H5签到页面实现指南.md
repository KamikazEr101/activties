# 前端H5签到页面实现指南

## 概述

前后端分离项目,前端需要开发一个H5签到页面,用户扫描二维码后跳转到此页面完成签到。

## 后端API接口

### 1. 验证Token接口

**接口**: `GET /h5/checkin/validate?token={token}`

**说明**: 扫码后首先调用此接口验证Token是否有效

**响应示例**:
```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "valid": true,
    "activityId": 1,
    "checkInToken": "eyJhbGci..."
  }
}
```

### 2. 提交签到接口

**接口**: `POST /h5/checkin`

**请求体**:
```json
{
  "checkInToken": "eyJhbGci...",
  "studentPhone": "13800138000"
}
```

**响应示例**:
```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "id": 1,
    "activityName": "新生计算机基础讲座",
    "studentName": "张三",
    "studentPhone": "13800138000",
    "checkInStatus": 1,
    "checkInStatusName": "已签到",
    "checkInTime": "2025-11-16T10:30:00"
  }
}
```

### 3. 获取页面配置(可选)

**接口**: `GET /h5/config`

**响应示例**:
```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "appName": "高校学生活动管理系统",
    "checkInTitle": "活动签到",
    "phonePlaceholder": "请输入报名手机号",
    "submitButtonText": "立即签到"
  }
}
```

#### 2. 创建签到页面组件

**CheckIn.vue**:
```vue
<template>
  <div class="check-in-page">
    <!-- 加载中 -->
    <van-loading v-if="loading" type="spinner" color="#1989fa" vertical>
      验证中...
    </van-loading>

    <!-- Token验证失败 -->
    <van-empty
      v-else-if="!tokenValid"
      :image="require('@/assets/error.png')"
      :description="errorMessage"
    >
      <van-button type="primary" @click="goBack">返回</van-button>
    </van-empty>

    <!-- 签到表单 -->
    <div v-else class="form-container">
      <div class="header">
        <h2>{{ config.checkInTitle }}</h2>
        <p class="subtitle">{{ config.appName }}</p>
      </div>

      <van-form @submit="handleSubmit">
        <van-cell-group inset>
          <van-field
            v-model="phone"
            type="tel"
            name="phone"
            :label="config.phonePlaceholder"
            placeholder="请输入11位手机号"
            :rules="[
              { required: true, message: '请输入手机号' },
              { pattern: /^1[3-9]\d{9}$/, message: '手机号格式不正确' }
            ]"
          />
        </van-cell-group>

        <div class="submit-btn">
          <van-button
            round
            block
            type="primary"
            native-type="submit"
            :loading="submitting"
          >
            {{ config.submitButtonText }}
          </van-button>
        </div>
      </van-form>

      <!-- 签到成功提示 -->
      <van-dialog
        v-model:show="showSuccess"
        title="签到成功"
        :message="successMessage"
        confirm-button-text="确定"
        @confirm="handleSuccessConfirm"
      />
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue';
import { useRoute, useRouter } from 'vue-router';
import { showToast, showDialog } from 'vant';
import axios from 'axios';

const route = useRoute();
const router = useRouter();

// 状态
const loading = ref(true);
const tokenValid = ref(false);
const errorMessage = ref('');
const checkInToken = ref('');
const activityId = ref(null);
const phone = ref('');
const submitting = ref(false);
const showSuccess = ref(false);
const successMessage = ref('');

// 配置
const config = ref({
  appName: '高校学生活动管理系统',
  checkInTitle: '活动签到',
  phonePlaceholder: '请输入报名手机号',
  submitButtonText: '立即签到'
});

// API基础URL
const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || 'http://localhost:8080';

// 页面加载时验证Token
onMounted(async () => {
  const token = route.query.token;
  
  if (!token) {
    tokenValid.value = false;
    errorMessage.value = '缺少签到凭证';
    loading.value = false;
    return;
  }

  try {
    // 验证Token
    const response = await axios.get(`${API_BASE_URL}/h5/checkin/validate`, {
      params: { token }
    });

    if (response.data.code === 200 && response.data.data.valid) {
      tokenValid.value = true;
      checkInToken.value = response.data.data.checkInToken;
      activityId.value = response.data.data.activityId;
      
      // 获取页面配置(可选)
      loadConfig();
    } else {
      tokenValid.value = false;
      errorMessage.value = response.data.msg || '二维码已失效';
    }
  } catch (error) {
    tokenValid.value = false;
    errorMessage.value = error.response?.data?.msg || '验证失败，请重试';
  } finally {
    loading.value = false;
  }
});

// 加载页面配置
const loadConfig = async () => {
  try {
    const response = await axios.get(`${API_BASE_URL}/h5/config`);
    if (response.data.code === 200) {
      config.value = response.data.data;
    }
  } catch (error) {
    console.error('加载配置失败:', error);
  }
};

// 提交签到
const handleSubmit = async () => {
  submitting.value = true;

  try {
    const response = await axios.post(`${API_BASE_URL}/h5/checkin`, {
      checkInToken: checkInToken.value,
      studentPhone: phone.value
    });

    if (response.data.code === 200) {
      const data = response.data.data;
      successMessage.value = `${data.studentName}，签到成功！\n活动：${data.activityName}\n时间：${data.checkInTime}`;
      showSuccess.value = true;
    } else {
      showToast({
        type: 'fail',
        message: response.data.msg || '签到失败'
      });
    }
  } catch (error) {
    const errorMsg = error.response?.data?.msg || '签到失败，请重试';
    showToast({
      type: 'fail',
      message: errorMsg
    });
  } finally {
    submitting.value = false;
  }
};

// 签到成功后的操作
const handleSuccessConfirm = () => {
  // 可以跳转到其他页面或关闭窗口
  phone.value = '';
  showSuccess.value = false;
};

// 返回
const goBack = () => {
  router.back();
};
</script>
```

### 方案二: React + Ant Design Mobile

**CheckIn.jsx**:
```jsx
import React, { useState, useEffect } from 'react';
import { useLocation } from 'react-router-dom';
import { Form, Input, Button, Toast, Dialog } from 'antd-mobile';
import axios from 'axios';
import './CheckIn.css';

const CheckIn = () => {
  const location = useLocation();
  const [loading, setLoading] = useState(true);
  const [tokenValid, setTokenValid] = useState(false);
  const [errorMessage, setErrorMessage] = useState('');
  const [checkInToken, setCheckInToken] = useState('');
  const [submitting, setSubmitting] = useState(false);

  useEffect(() => {
    const params = new URLSearchParams(location.search);
    const token = params.get('token');

    if (!token) {
      setTokenValid(false);
      setErrorMessage('缺少签到凭证');
      setLoading(false);
      return;
    }

    validateToken(token);
  }, []);

  const validateToken = async (token) => {
    try {
      const response = await axios.get('/h5/checkin/validate', {
        params: { token }
      });

      if (response.data.code === 200 && response.data.data.valid) {
        setTokenValid(true);
        setCheckInToken(response.data.data.checkInToken);
      } else {
        setTokenValid(false);
        setErrorMessage(response.data.msg || '二维码已失效');
      }
    } catch (error) {
      setTokenValid(false);
      setErrorMessage('验证失败，请重试');
    } finally {
      setLoading(false);
    }
  };

  const onFinish = async (values) => {
    setSubmitting(true);

    try {
      const response = await axios.post('/h5/checkin', {
        checkInToken,
        studentPhone: values.phone
      });

      if (response.data.code === 200) {
        const data = response.data.data;
        Dialog.alert({
          title: '签到成功',
          content: `${data.studentName}，签到成功！\n活动：${data.activityName}\n时间：${data.checkInTime}`
        });
      } else {
        Toast.show({
          icon: 'fail',
          content: response.data.msg || '签到失败'
        });
      }
    } catch (error) {
      Toast.show({
        icon: 'fail',
        content: error.response?.data?.msg || '签到失败，请重试'
      });
    } finally {
      setSubmitting(false);
    }
  };

  if (loading) {
    return (
      <div className="loading-container">
        <div className="loading-spinner">验证中...</div>
      </div>
    );
  }

  if (!tokenValid) {
    return (
      <div className="error-container">
        <h2>签到失败</h2>
        <p>{errorMessage}</p>
      </div>
    );
  }

  return (
    <div className="check-in-page">
      <div className="form-container">
        <div className="header">
          <h2>活动签到</h2>
          <p>高校学生活动管理系统</p>
        </div>

        <Form
          onFinish={onFinish}
          footer={
            <Button
              block
              type="submit"
              color="primary"
              loading={submitting}
              size="large"
            >
              立即签到
            </Button>
          }
        >
          <Form.Item
            name="phone"
            label="手机号"
            rules={[
              { required: true, message: '请输入手机号' },
              { pattern: /^1[3-9]\d{9}$/, message: '手机号格式不正确' }
            ]}
          >
            <Input placeholder="请输入11位手机号" type="tel" />
          </Form.Item>
        </Form>
      </div>
    </div>
  );
};

export default CheckIn;
```

## 测试流程

1. **生成二维码**: 管理员调用 `GET /registration/1/qrcode`
2. **复制链接**: 从返回的 `qrContent` 中复制链接
3. **访问H5页面**: 在浏览器打开链接或用手机扫码
4. **输入手机号**: 输入已报名的手机号
5. **提交签到**: 点击签到按钮
6. **查看结果**: 显示签到成功或失败信息

## 常见问题

### Q1: CORS跨域问题?
A: 后端需要配置CORS,在`WebMvcConfiguration`中添加:
```java
@Override
public void addCorsMappings(CorsRegistry registry) {
    registry.addMapping("/**")
        .allowedOrigins("*")
        .allowedMethods("*")
        .allowedHeaders("*");
}
```

### Q2: 如何在微信中分享?
A: 需要配置微信JS-SDK,设置分享标题、描述和图片

### Q3: Token过期怎么办?
A: 前端应该提示"二维码已失效",引导用户联系工作人员刷新

### Q4: 手机号校验失败?
A: 确保手机号格式为11位,且以1开头,第二位为3-9

前后端分离项目的H5签到页面实现非常简单:
1. 后端提供验证Token和签到两个接口
2. 前端只需要一个H5页面,扫码后获取Token
3. 用户输入手机号提交签到
4. 显示签到结果

选择任一前端方案实现即可,推荐使用Vue 3 + Vant以获得最佳移动端体验。
